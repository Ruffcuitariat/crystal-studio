# Crystal Studio

双击 `Crystal-Studio.html`，使用 Chrome 或 Edge 打开。该文件包含全部依赖，断网也可使用，不需要安装或启动服务器。CIF 文件只在本地浏览器中处理。

## 结构与操作

- 点击“导入 CIF”，或者将 CIF 文件拖入页面。
- 鼠标左键拖动旋转，滚轮缩放，右键拖动平移；触屏单指旋转、双指缩放和平移。
- 工具栏提供适应视窗、缩放、自动旋转、重置视角与全屏。
- 左上角的 a、b、c 切换为沿晶轴观察；立方体按钮回到等轴视角。
- 点击球体可查看元素、笛卡尔坐标和分数坐标。
- 球棍、空间填充、棍状三种显示方式可切换。

## 外观

- 原子：整体大小、每种元素的颜色与半径，以及元素可见性。
- 化学键：显示开关、半径、跟随两端元素配色或统一颜色。
- 成键方式：共价半径系数，或指定最大原子间距（Å）。化学键由几何距离推断，不是化学键级或配位数的计算结果；应结合材料本身选择阈值。
- 超晶胞：分别设置 a、b、c 方向的整数倍数后，点击旁边的勾号应用。
- 可切换晶胞边框、边界原子、正交或透视投影，以及预览背景。
- 右侧外观设置区域可以滚动，桌面上的导出区域保持可见。

## PNG 导出

保留“透明背景”勾选，选择图像尺寸，点击“导出 PNG”。提供 1600 × 1200、2400 × 1800、3200 × 2400、4096 × 3072 四种尺寸。

导出包含当前的原子、化学键和可见晶胞边框；不包含背景网格、界面、元素图例或坐标指示器。导出保持当前观察方向、平移与缩放；画幅为 4:3，视窗长宽比不同时会增加留白以保留可见内容。取消透明背景后，使用白色或所选深灰色背景。

## CIF 支持范围

支持通常的 CIF 文本文件、分数坐标、笛卡尔坐标、非正交晶胞、多数据块，以及明确列出的空间对称操作（旧式 `_symmetry_equiv_pos_as_xyz` 或现代 `_space_group_symop_operation_xyz` / 点分隔标签）。对称操作通过 3Dmol.js 展开，并去除特殊位置的重复原子。

如果文件仅包含不对称单元和空间群名称，没有列出对称操作，工具不会仅根据空间群名称补全晶胞。请从原软件导出包含完整对称操作或完整晶胞的 CIF；检测到此情况时页面会给出提示。

部分占位会以占位点显示，并提示其含义；不同元素的重叠占位可能相互遮挡。不显示磁矩、调制结构、配位多面体、热椭球或轨道。空间填充模式采用范德华半径作为初始尺寸，并响应各元素的半径调整。

单个文件上限为 20 MB，展开或扩胞后的原子数上限为 12,000，每个晶轴倍数范围为 1–8。大结构建议先以 1 × 1 × 1 导入。

## 示例来源与文件

默认 BiOCl 示例的晶胞与原子位置来自用户提供的 Materials Project 历史页面：
https://legacy.materialsproject.org/materials/mp-22939/

晶胞 a = b = 3.913872 Å，c = 7.827791 Å；示例直接列出完整晶胞的 6 个原子，默认显示 2 × 2 × 1 超晶胞与边界原子。页面的成键结果由本工具的距离规则生成，与原页面使用的 CrystalNN 算法可能不同。

- `Crystal-Studio.html`：独立离线成品，只需此文件即可使用。
- `index.html`、`style.css`、`app.js`、`vendor/`：可修改的源文件。
- `build.mjs`：重新生成独立 HTML，运行 `node build.mjs`。
- `qa/`：浏览器功能测试、截图、透明 PNG 测试样本与结果。

3D 渲染使用 Three.js r128，坐标和对称操作解析使用 3Dmol.js 2.4.2，图标使用 Lucide 0.468.0。第三方许可见 `vendor/*LICENSE.txt`，并内嵌于独立 HTML 中。
